# App Estética

Repositorio base para construir una aplicación/landing operativa para negocios de estética, enfocada en captación, reserva de citas, seguimiento comercial y automatización ligera.

## Objetivo

Crear un sistema digital simple para un negocio de estética que permita:

- Presentar servicios de forma clara.
- Captar leads o solicitudes de cita.
- Derivar conversaciones a WhatsApp o agenda.
- Registrar consultas con datos mínimos útiles.
- Preparar una base escalable para automatizaciones posteriores.

## Estado actual

Fase inicial del repositorio.

Antes de desarrollar funcionalidades complejas, el proyecto debe definir:

1. Stack técnico.
2. Alcance funcional del MVP.
3. Estructura de páginas.
4. Flujo de captación y reserva.
5. Integraciones previstas.
6. Reglas de diseño, copy y QA.

## Principio de trabajo

Primero claridad de negocio. Después interfaz. Después automatización.

No se deben introducir dependencias, integraciones o arquitecturas complejas sin justificar su impacto directo en captación, conversión o gestión operativa.
