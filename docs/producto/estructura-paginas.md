# Estructura de páginas — App Estética

## Arquitectura recomendada inicial

```text
/
/servicios
/contacto
/gracias
/legal/privacidad
/legal/cookies
/legal/aviso-legal
```

## Home

Objetivo: explicar el valor, generar confianza y llevar a una acción clara.

Secciones recomendadas:

1. Hero con propuesta de valor.
2. Servicios principales.
3. Beneficios o problemas que resuelve.
4. Proceso de reserva o contacto.
5. Prueba social o confianza.
6. CTA final.

## Servicios

Objetivo: mostrar tratamientos o servicios de forma comprensible y accionable.

Cada servicio debe incluir:

- Nombre claro.
- Para quién es.
- Qué problema o deseo resuelve.
- Duración aproximada si aplica.
- Precio si el negocio decide mostrarlo.
- CTA a consulta o reserva.

## Contacto

Objetivo: reducir fricción y capturar solicitudes útiles.

Campos mínimos recomendados:

- Nombre.
- Teléfono o WhatsApp.
- Servicio de interés.
- Mensaje opcional.
- Consentimiento legal.

## Página de gracias

Objetivo: confirmar recepción y orientar el siguiente paso.

Debe incluir:

- Confirmación clara.
- Tiempo estimado de respuesta si se conoce.
- Botón a WhatsApp si se quiere acelerar la conversación.
- Enlace de vuelta a inicio.

## Legal

Las páginas legales deben adaptarse al negocio real antes de publicación.

No publicar formularios ni tracking sin revisar textos legales, cookies y consentimiento.
