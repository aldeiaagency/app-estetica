# Stack técnico pendiente de decisión

Este repositorio aún no debe asumir stack definitivo sin decisión explícita.

## Opciones razonables

### Opción recomendada para landing rápida

- Astro o Next.js.
- Tailwind CSS.
- Formulario conectado a webhook/n8n o proveedor de formularios.
- Deploy en Vercel, Netlify o hosting compatible.

### Opción recomendada para app con panel futuro

- Next.js.
- Supabase.
- Tailwind CSS.
- Resend o proveedor de email transaccional.
- n8n para automatizaciones externas.

## Criterio de elección

Usar landing rápida si el objetivo inmediato es captar leads.

Usar app con panel solo si existe necesidad real de usuarios, gestión interna, autenticación, base de datos o reservas avanzadas.

## Decisión pendiente

Antes de escribir código de aplicación, definir:

- Framework.
- Deploy.
- Gestión de formularios.
- Destino de leads.
- Necesidad o no de base de datos.
- Integraciones iniciales.
